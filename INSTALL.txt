GRIDIRON IQ — GITHUB 403 RATE-LIMIT FIX
========================================

WHY IT FAILED
-------------
Your importer is calling:

https://api.github.com/repos/nflverse/nflverse-data/releases/tags/stats_player

Unauthenticated GitHub API requests have a limited request allowance. Render
can also share outbound IP addresses with other services, so the limit can be
used up even when you did not personally make many requests.

THIS PATCH
----------
The replacement never calls api.github.com. It requests the nflverse release
CSV assets directly and retains your cached 2025 CSV as a fallback.

INSTALLATION
------------
1. Open app.py.

2. Search for every occurrence of:
       api.github.com/repos/nflverse/nflverse-data/releases/tags/stats_player

3. Remove the old GitHub release-discovery function or make sure the 2025
   import route no longer calls it.

4. Find your current:
       def _pr_rows(...):

5. Replace the entire _pr_rows function with the code in:
       player_research_direct_download_fix.py

6. Also copy these helper items from that file above _pr_rows:
       NFLVERSE_PLAYER_RELEASE
       _pr_direct_urls
       _looks_like_csv
       _normalize_player_rows

7. Verify these imports exist:
       import csv
       import io
       import requests

8. Verify DATA_DIR and app already exist before _pr_rows runs.

9. Commit app.py to GitHub and redeploy the latest commit on Render.

10. Click the Player Research 2025 update button once.

IMPORTANT
---------
Do not leave the old GitHub API lookup in the update route. Replacing only the
CSV loader will not help if another function still calls api.github.com first.

Search app.py for all of these terms:
    api.github.com
    releases/tags/stats_player
    assets_url
    browser_download_url

The 2025 import path should use _pr_rows(2025, force=True) directly.

OPTIONAL TEMPORARY ALTERNATIVE
------------------------------
A GITHUB_TOKEN environment variable can raise API limits, but the direct
download solution is better because this import does not need the GitHub API.
